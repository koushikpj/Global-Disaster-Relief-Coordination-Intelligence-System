# Global Disaster Relief Coordination Intelligence System

## 📌 About the Project
A platform that connects disaster‑affected communities with volunteers and NGOs.  
It intelligently matches urgent needs with available resources to ensure faster response and effective humanitarian aid.

## 🚀 Features
- Post requests for urgent resources (food, medicine, shelter, etc.)
- Volunteers and NGOs can contribute available resources
- Smart matching of needs with resources
- Dashboard with analytics and charts for monitoring
- Transparent card‑style UI synced with background themes

## 🛠️ Tech Stack
- **Frontend:** HTML, CSS3, EJS  
- **Backend:** Node.js, Express.js  
- **Database:** MongoDB  
- **Other Tools:** Multer (file uploads), GitHub for version control

## 📂 Project Structure
- `home.ejs` – Landing page with background sync design  
- `dashboard.ejs` – Analytics dashboard with charts and tables  
- `add-resource.ejs` – Form to post available resources  
- `add-request.ejs` – Form to request urgent resources  
- `public/css/` – Stylesheets with background images (g3, g4, etc.)

## 🎯 Objective
To provide a scientific and professional system for disaster relief coordination, ensuring optimized resource allocation and faster humanitarian response.
